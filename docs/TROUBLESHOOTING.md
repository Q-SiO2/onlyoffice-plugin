# Troubleshooting

| Symptom                                 | Practical fix                                                                                                                                                                                                                            |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plugin absent                           | Open the Presentation Editor, not Word/Sheets. Require 8.3+. Check config.json is at .plugin ZIP root, install through My plugins, reopen editor. For folder installation, use only the exact custom GUID folder.                        |
| Plugin shows blank panel                | Rebuild, reinstall and reopen. Check packaged app.js/app.css/vendor/plugins.js. Open plugin iframe DevTools for syntax errors. No CDN is required.                                                                                       |
| Plugin cannot connect / Failed to fetch | Check API health from laptop, backend URL/port, server is running and CORS allowlist. Newer builds use onlyoffice://plugin; observed 9.3 local builds need Origin null. Use the browser presenter fallback.                              |
| CORS error                              | OPTIONS must return 204, allow Authorization and Content-Type, and echo one configured origin. Add the actual origin to ALLOWED_ORIGINS; restart. Do not disable browser security or duplicate CORS headers at the proxy.                |
| Supabase not configured                 | This v1 uses SQLite/Socket.IO and needs no Supabase environment variables. Check DATABASE_PATH, secrets, file permissions and Node 24+. Switching to Supabase requires code changes, not a setting.                                      |
| QR opens wrong address                  | Set PUBLIC_URL to the phone-accessible web URL, restart backend, display a freshly generated QR. Old slide QR images are snapshots; replace/reinsert manually. Old session QR codes remain tied to their old session.                    |
| localhost inaccessible from phones      | localhost resolves to the phone. Use the laptop LAN IP with port 3000 (built) or 5173 (Vite); phones and laptop must share a network permitting peer access.                                                                             |
| Firewall/guest Wi-Fi issue              | Test /api/health on a phone. Ask the network administrator to allow the intended private-network port or remove client isolation; a dedicated trusted router/hotspot may be simpler. The app does not change firewall policies.          |
| Phone rejected                          | Verify digits and access code privately, preserve leading zeros in CSV, use Moroccan 06/07 or +212 forms, review import warnings. A wrong code intentionally looks the same as an unknown number. Wait a minute after repeated attempts. |
| Login replaced                          | Another device used the same phone+correct code, rotating the session token. Do not share codes; reconnect on the intended device. Recorded votes stay attached to that participant.                                                     |
| Realtime updates missing                | Check connection indicator, Wi-Fi, backend and WebSocket proxy. HTTP reconciles every 10 seconds/on visibility. Phones can sleep; keep page open, unlock and allow reconnection. Counters reflect active sockets.                        |
| Participant appears to vote twice       | Repeated request UUIDs acknowledge the same stored vote; they do not add another row. Reset explicitly starts a new epoch. Inspect anonymous total or DB uniqueness; a second code/participant is a separate identity.                   |
| Offline vote not saved                  | A queue retries until acknowledged, but late unsaved votes are rejected after close or scene/epoch change. Do not claim offline submission succeeded until the confirmation is shown.                                                    |
| Results not updating                    | Presenter preview is private/live; projector sees aggregates only in RESULTS. Close voting then show results. Verify the projector session UUID matches the current one. Inserted slide PNGs are snapshots, not live.                    |
| Invalid transition / stale state        | Close voting before changing scenes; a teammate may have just changed state. Wait for the fresh snapshot and retry deliberately.                                                                                                         |
| Insertion fails                         | Return to edit mode, select an editable slide, use a blank slide, inspect callCommand errors. On timeout check the slide before retrying. Download PNG from browser presenter as a fallback.                                             |
| Cannot operate sidebar in slideshow     | Have a teammate use /presenter, or exit slideshow to use panel/insertions. Plugin windows are not guaranteed to overlay fullscreen shows.                                                                                                |
| ONLYOFFICE update changes behavior      | Rehearse after updates; check current SDK/API and origin. Rebuild/reinstall; use browser presenter/projector fallback. Preserve original presentation before testing insertions.                                                         |
| Deployment loses votes                  | SQLite must live on persistent disk. Do not use ephemeral/serverless disks. Run one instance only. Restore using controlled backup and preserve HMAC key.                                                                                |
| HTTP 429                                | Shared-IP login and per-phone/vote rate limits prevent bursts/guessing; wait one minute. Set TRUST_PROXY to the actual proxy hop count so all clients are not mistaken for the proxy.                                                    |
| npm engine / sqlite error               | Install Node 24+. Run commands at repository root. No separate SQLite npm native module is required.                                                                                                                                     |
| Port in use                             | Stop the previous demo/server normally. Vite uses strict port 5173; configure ports/proxy consistently if changing them.                                                                                                                 |
| Import output already exists            | Use a new private output filename; the tool does not overwrite previously distributed credentials. Review warnings/exit status 2.                                                                                                        |

Collect reproducible steps, state/scene and a sanitized error message. Do not post phone inputs, individual codes, tokens or private CSVs in support logs. Browser traces are synthetic during automated tests but should still be kept private for real-class debugging.
