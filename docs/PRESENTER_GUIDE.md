# Guide du présentateur

Le serveur est déjà hébergé sur Railway. Aucun serveur à lancer sur votre ordinateur.

## Préparer, plusieurs jours avant

1. Ouvrez https://paloalto-live-production.up.railway.app/presenter et choisissez **Créer une présentation**.
2. Entrez votre e-mail d’organisateur, un titre et le code proposé. Conservez e-mail + code pour revenir. Aucun e-mail n’est envoyé.
3. **Scènes & questions** : ajoutez et réordonnez les scènes, écrivez les questions/réponses, mots et notes. Choisissez la durée du vote. Cliquez **Enregistrer les scènes**.
4. **Votants** : saisissez chaque nom et numéro marocain. Le même numéro met à jour la ligne existante. Aucun CSV ni code individuel à distribuer.
5. Pour préparer vos diapositives, ouvrez **Présenter**, sélectionnez une scène pour l’aperçu et collez le lien participant dans le plugin ONLYOFFICE. Ajoutez les graphiques, puis déplacez/redimensionnez-les avec les poignées. L’aperçu ne démarre pas les votes.

## Le jour J

1. Revenez avec e-mail + code, ouvrez **Présenter** et partagez QR/lien + code. Gardez l’e-mail d’organisateur privé.
2. Les votants se connectent avec leur numéro autorisé et ce code.
3. Après votre vidéo/scène, cliquez **Ouvrir le vote**. Le compte à rebours ferme le vote et affiche les résultats automatiquement. Avec une durée de 0, utilisez **Fermer et afficher les résultats**.
4. Cliquez **Scène suivante**, puis ouvrez son vote quand vous êtes prêt. Les votants restent connectés.
5. Terminez la présentation et exportez les résultats si vous le souhaitez.

Les questions se verrouillent après le démarrage. Gardez les graphiques non groupés et le plugin ouvert/connecté pour les mises à jour. Répétez l’insertion et l’actualisation dans ONLYOFFICE, y compris en plein écran, avant le cours. Le lancement des vidéos et l’avancement des scènes restent manuels.
