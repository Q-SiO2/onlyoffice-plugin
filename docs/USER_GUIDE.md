# Guide étudiant

1. Scannez le QR code affiché au début du cours.
2. Entrez votre numéro mobile marocain et le code personnel remis par votre enseignant. `06…`, `07…`, `+212…` et `00212…` sont acceptés.
3. Une fois connecté, gardez la page ouverte. Vous n’avez pas besoin de scanner un autre QR code pour chaque scène.
4. Regardez la scène. Quand le vote apparaît, choisissez votre réponse.
5. Si vous le souhaitez, choisissez les mots qui expliquent votre impression. Le nombre maximum est indiqué.
6. Appuyez sur **Envoyer ma réponse**. Attendez **Votre réponse a été enregistrée**.
7. Votre téléphone revient automatiquement au statut d’attente quand l’enseignant ferme le vote. La prochaine activité apparaît sans actualisation.

Vos réponses sont affichées sous forme de totaux anonymes. Votre numéro et votre code ne sont pas projetés. Ne partagez pas votre code personnel. Une deuxième connexion avec le même numéro/code remplace l’ancienne connexion, mais ne permet pas de voter deux fois.

**Connexion interrompue :** gardez la page ouverte, vérifiez le Wi-Fi, puis attendez la reconnexion. Une réponse sans confirmation est réessayée. Si le vote ferme avant que le serveur la reçoive, elle ne peut plus être enregistrée. Actualiser la page conserve normalement votre connexion et votre réponse déjà enregistrée. Le navigateur privé ou l’effacement du stockage peut demander une nouvelle connexion.

**Numéro non reconnu ou code incorrect :** vérifiez votre numéro et le code fourni; demandez à l’enseignant de vérifier la liste. Après plusieurs erreurs rapprochées, attendez une minute.

**Session terminée :** le message **Merci pour votre participation** vous indique que vous pouvez fermer la page. La connexion concerne cette présentation uniquement.
